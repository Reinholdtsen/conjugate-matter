*The lab notebook, artifact #1, is the program's first formal write-up: version 0.1, dated September 2026, with five postulates, an action, checks against established physics, a predictions table with kill conditions, and a ranked list of open problems. As the first calculations came in, their results were appended as addenda v0.2 to v0.6 rather than edited into the text, so the notebook preserves the order in which the program changed. Because the body was never revised, claims that later died, momentum-space clumping among them, still read there as live. It was superseded as a reference by the program v1.0 (#9) and then by the checkpoint #11, and it is kept as the audit trail.*

**Status:** Record, superseded as reference — v0.1 uses the tags [P], [D], [T] and [O] only (no †, [S] or [V]), and the addenda are untagged — superseded by #9 and then #11 (`HANDOFF.md` §3: "v0.6 — superseded as reference"; root `CLAUDE.md`: "the audit trail, superseded as reference but kept"). No `verify/` script checks its §0–§12.
